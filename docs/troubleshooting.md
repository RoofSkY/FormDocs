# 문제 해결

## 점검 화면 (`?check=1`)

웹앱 주소 끝에 `?check=1`을 붙여 엽니다. 신청서 목록 화면 맨 아래의 **관리자: 양식 점검** 링크로도 열 수 있습니다.

```text
https://script.google.com/macros/s/…/exec?check=1
```

점검 화면을 열면:

- 캐시를 비우고 템플릿 시트와 모든 양식 문서를 새로 읽습니다. `양식목록` 탭을 고친 내용이 바로 반영됩니다.
- 양식마다 상태를 보여 줍니다.

| 상태 | 뜻 |
| --- | --- |
| **정상** | 사용할 수 있습니다. 입력 칸 개수, 저장 위치, 파일 이름 규칙을 함께 보여 줍니다. |
| **확인 필요** | 사용할 수 있지만 확인할 점이 있습니다. 예) 그림이 웹 화면에 보이지 않음 |
| **오류** | 사용할 수 없습니다. 어디를 어떻게 고칠지 알려 줍니다. |
| **사용 안 함** | `사용` 체크가 해제된 양식입니다. |

오류 문구 앞의 `[…]`는 고칠 위치입니다.

| 위치 표시 | 고칠 곳 |
| --- | --- |
| `[config.gs]` | 개발 담당자가 `config.gs`를 고친 뒤 배포 버전을 갱신합니다. |
| `['양식목록' 탭 3행]` | 템플릿 시트 `양식목록` 탭의 해당 행 |
| `['양식목록' 탭 1행(머리글)]` | `양식목록` 탭의 머리글 |
| `[양식문서 '문서 이름']` | 해당 양식 문서. 문구에 나온 `{{…}}`를 **Ctrl+F**로 찾아 고칩니다. |

> 문서 문제를 먼저 고치면 그다음에 저장 폴더를 확인합니다. 오류를 고친 뒤 점검 화면을 새로고침하세요.

## 오류 문구별 해결법

### 설치·설정

| 문구 | 해결 |
| --- | --- |
| `TEMPLATE_SPREADSHEET_ID가 비어 있습니다` | `setup` 실행 후 로그의 시트 ID를 `config.gs`에 넣고 배포 버전을 갱신합니다. ([설치 가이드](install.md)) |
| `TEMPLATE_SPREADSHEET_ID의 스프레드시트를 열 수 없습니다` | ID가 맞는지, 배포 계정이 그 시트를 열 수 있는지 확인합니다. |
| `DEFAULT_FOLDER_ID의 폴더를 열 수 없습니다` | 폴더 ID와 배포 계정의 편집 권한을 확인합니다. |
| `setup 함수는 웹앱을 배포한 계정으로 Apps Script 편집기에서만 실행할 수 있습니다` (`resetSampleForms`도 같음) | 배포 계정으로 로그인해 편집기에서 실행합니다. |
| `ReferenceError: … is not defined`, `include_ is not defined`, `파일을 찾을 수 없습니다` 같은 오류 | 편집기에 붙여 넣지 않은 파일이 있습니다. 스크립트 6개(`Code`, `Form`, `Document`, `Setup`, `Util`, `config`)와 HTML 3개(`index`, `stylesheet`, `javascript`)가 모두 있는지, 이름이 같은지 확인한 뒤 배포 버전을 갱신합니다. ([설치 가이드](install.md#1-apps-script-프로젝트-만들기)) |

### `양식목록` 탭

| 문구 | 해결 |
| --- | --- |
| `템플릿 시트에 '양식목록'이 없습니다` | 탭 이름을 `양식목록`으로 정확히 바꿉니다. |
| `머리글 '…'이(가) 없습니다` | 1행에 머리글을 정확히 적습니다. 필요한 머리글: 양식ID, 양식이름, 설명, 양식문서, 저장폴더ID, 파일이름, 사용 |
| `'…' 머리글이 두 번 있습니다` | 같은 머리글 하나를 지웁니다. |
| `양식ID가 비어 있습니다` / `영문, 숫자, -, _만 쓸 수 있습니다` | `vacation`처럼 영문·숫자로 적습니다. 한글·띄어쓰기는 쓸 수 없습니다. |
| `양식ID '…'이(가) N행에도 있습니다` | 겹치지 않게 바꿉니다. 대소문자만 다른 것도 같은 ID로 봅니다. |
| `양식이름이 비어 있습니다` | 화면 제목으로 쓸 이름을 적습니다. |
| `'사용' 칸의 '…'을 알 수 없습니다` | 체크박스로 바꾸거나 비웁니다. |
| `양식문서가 비어 있습니다` / `주소 형식이 올바르지 않습니다` | Google 문서 주소(`https://docs.google.com/document/d/…/edit`)를 통째로 붙여 넣습니다. |
| `양식문서를 열 수 없습니다` | 주소가 맞는지, 배포 계정에 문서가 공유되어 있는지 확인합니다. |
| `양식문서가 Google 문서가 아닙니다` | Word·한글 파일은 **파일 → Google 문서로 저장**한 뒤 그 주소를 넣습니다. |
| `양식문서가 휴지통에 있습니다` | 복원하거나 다른 문서를 지정합니다. |
| `저장폴더ID 형식이 올바르지 않습니다` | Drive 폴더 주소를 통째로 붙여 넣거나 `folders/` 뒤의 글자만 적습니다. |
| `저장폴더ID의 폴더를 열 수 없습니다` / `휴지통에 있습니다` | 배포 계정에 **편집자**로 공유하거나 폴더를 복원합니다. |
| `파일이름의 {{…}}은(는) 양식 문서에 없는 이름입니다` | 문서의 항목 이름이나 공통 자리표시자와 똑같이 적습니다. (하위폴더도 같음) |
| `중괄호 짝이 맞지 않습니다` (파일이름·하위폴더) | `{{항목명}}`처럼 양쪽에 두 개씩 적습니다. |

### 양식 문서

| 문구 | 해결 |
| --- | --- |
| `입력 칸이 하나도 없습니다` | 값을 받을 자리에 `{{항목명}}`을 적습니다. |
| `'…' 부분의 중괄호 짝이 맞지 않습니다` | `{이름}`, `{{이름}` 등을 `{{이름}}`으로 고칩니다. |
| `자리표시자 안에 줄바꿈이 있습니다` | `{{ }}` 안을 한 줄로 적습니다. |
| `항목 이름이 없습니다` | `{{: select(남, 여)}}` → `{{성별: select(남, 여)}}` |
| `항목 이름에 * 나 = 기호가 들어 있습니다` | `*`는 이름 바로 뒤에, 표시조건은 콜론 뒤에 적습니다. |
| `'…'은(는) 알 수 없는 설정입니다. 유형(text, select, multi, agree, sign), required, if 항목=값, help 중에서 영어 소문자로 적으세요.` | 유형 이름 오타, 콜론 누락, 한글 지시자(`목록선택`, `필수`, `안내` 등)를 확인합니다. 지시자는 [영어 소문자](placeholder-syntax.md#지시자-한눈에-보기)로 적습니다. 예) `목록선택(남, 여)` → `select(남, 여)` |
| `지시자는 영어 소문자로만 적습니다. 'Select' → 'select'` | 대문자를 소문자로 고칩니다. `Help`, `IF`, `Required` 등도 같습니다. |
| `공통 자리표시자는 소문자로만 적습니다. {{Date}} → {{date}}` | `{{Date}}`, `{{FORM_NAME}}` 등을 소문자로 고칩니다. |
| `유형을 두 번 적었습니다` | 유형은 하나만 적습니다. |
| `괄호 짝이 맞지 않습니다. 선택지는 select(남, 여)처럼 괄호로 감싸세요.` | `select(남, 여)`처럼 괄호를 닫습니다. |
| `선택지가 없습니다` | 괄호 안에 고를 값을 쉼표로 적습니다. |
| `선택지 '…'이 두 번 적혀 있습니다` | 같은 선택지 하나를 지웁니다. |
| `'…' 유형은 괄호 선택지를 쓰지 않습니다. 고르는 항목이라면 select·multi·agree 중 하나로 적으세요.` | 고르는 항목이면 `select`·`multi`·`agree` 중 하나로 바꿉니다. 예) `{{이름: text(가, 나)}}` → `{{이름: select(가, 나)}}` |
| `… 설정이 서로 다릅니다` | 같은 항목의 설정은 한 곳에만 적고, 나머지는 `{{이름}}`처럼 이름만 적습니다. |
| `'…'은(는) 공통 자리표시자라 설정을 붙일 수 없습니다. 입력받으려면 '신청 날짜'처럼 다른 이름을 쓰세요.` | `{{date*}}` 같은 설정을 지우거나, 입력받으려면 `{{신청 날짜*}}`처럼 다른 이름을 씁니다. |
| `표시조건은 앞에 if를 붙여 적습니다. '…' → 'if …'` | `{{동행인: 귀가방식=동행귀가}}` → `{{동행인: if 귀가방식=동행귀가}}` |
| `if 뒤에 '항목=값'을 적으세요.` | `if`만 적고 조건을 빠뜨렸습니다. 예) `if 귀가방식=동행귀가` |
| `표시조건은 'if 항목=값' 형식으로 적으세요.` | `=` 앞뒤에 항목과 값을 모두 적습니다. 예) `{{동행인: if 귀가방식=동행귀가}}` |
| `표시조건은 하나만 적을 수 있습니다. 여러 값은 if 귀가방법=버스/기타처럼 / 로 이으세요.` | `if`를 하나만 남기고, 여러 값은 `/` 또는 `or`로 잇습니다. 예) `if 귀가방법=버스 or 기타` |
| `표시조건에 쓴 '…' 항목은 문서에서 이 항목보다 앞에 나와야 합니다` | 조건 항목을 문서 앞쪽으로 옮기거나, 그 항목의 설정을 앞쪽 자리로 옮깁니다. |
| `표시조건에 쓴 '…'이라는 항목이 문서에 없습니다` | 조건의 항목 이름을 문서와 똑같이 적습니다. |
| `표시조건에는 select·multi·agree 유형 항목만 쓸 수 있습니다.` | 조건 항목을 고르는 유형으로 바꿉니다. |
| `'…'의 선택지에 '…'이(가) 없습니다` | 조건 값을 선택지와 똑같이 적습니다. |
| `자기 자신을 표시조건으로 쓸 수 없습니다` | 다른 항목을 조건으로 씁니다. |
| `머리글·바닥글·다른 탭에는 설정 없이 {{…}}처럼 이름만 적으세요` | 설정은 첫 탭 본문에 적고, 머리글·바닥글에는 이름만 적습니다. |
| `머리글·바닥글·다른 탭의 자리표시자는 본문에 있는 항목이어야 합니다` | 본문에 같은 이름의 항목을 두거나 이름을 맞춥니다. |

## 사용자 화면에 나오는 메시지

| 화면 | 원인 | 해결 |
| --- | --- | --- |
| 신청서를 찾을 수 없습니다 | 주소의 `form=` 뒤 글자와 같은 양식ID가 없습니다. | 주소와 양식ID를 확인합니다. |
| 지금은 접수하지 않는 신청서입니다 | `사용` 체크가 해제되어 있습니다. | 접수하려면 체크합니다. |
| 신청서를 열 수 없습니다 / 관리자 확인 사항 | 설정 오류가 있습니다. | 화면에 나온 내용대로 고치거나 `?check=1`로 확인합니다. |
| 신청서가 바뀌었습니다 | 사용자가 작성하는 동안 관리자가 항목을 고쳤습니다. | 사용자에게 새로고침 후 다시 작성하도록 안내합니다. |
| 제출 중 문제가 생겼습니다 | 일시적인 Google 서비스 오류 등입니다. | 잠시 후 다시 제출합니다. 반복되면 편집기의 **실행** 기록을 확인합니다. |
| 이 화면은 웹앱 주소에서 열어야 제출할 수 있습니다 | 웹앱이 아닌 곳에서 HTML을 열었습니다. | 배포된 웹앱 주소로 엽니다. |

## 자주 묻는 질문

**문서를 고쳤는데 웹 화면이 그대로예요.**
신청서 페이지를 새로고침하세요. 양식 문서는 수정 시각을 비교해 바로 반영됩니다. `양식목록` 탭을 고쳤다면 `?check=1`을 한 번 여세요.

**코드를 고쳤는데 반영이 안 돼요.**
`/exec` 주소는 배포 버전을 갱신해야 바뀝니다. **배포 → 배포 관리 → 수정 → 새 버전 → 배포**를 하세요. ([설치 가이드](install.md#코드를-고친-뒤-반영하기))

**그림이 웹 화면에 안 보여요.**
그림·머리글·바닥글은 웹 화면에 보이지 않습니다. 결과 문서에는 그대로 들어갑니다. 꼭 읽어야 할 내용은 글자로 적으세요.

**서명 때문에 문서 줄이 밀려요.**
서명 자리표시자를 표 칸 안에 두세요. 서명 그림 크기는 `config.gs`의 `SIGNATURE_MAX_WIDTH`, `SIGNATURE_MAX_HEIGHT`로 바꿀 수 있습니다.

**입력값 서식이 이상해요.**
입력값은 자리표시자 `{{` 바로 뒤 첫 글자의 서식을 따릅니다. 자리표시자 전체에 원하는 글꼴·크기를 주세요.

**`{{submitter}}`가 비어 있어요.**
이 웹앱은 액세스 권한 **모든 사용자**(로그인 없이 작성)로 배포하므로 제출자 이메일을 알 수 없습니다. 제출한 사람은 `{{성명*}}`처럼 입력 칸으로 받으세요.

**`{{날짜}}`, `{{양식이름}}` 자리에 입력 칸이 생겨요.**
공통 자리표시자는 영어 소문자 이름(`{{date}}`, `{{form_name}}` 등)만 인식합니다. 예전 한글 이름은 오류 없이 일반 입력 칸이 되므로 영어 이름으로 바꾸세요. ([공통 자리표시자](placeholder-syntax.md#공통-자리표시자))

**제출 완료 화면의 문서 링크가 열리지 않아요.**
문서는 배포 계정의 Drive에 저장되므로 권한이 없으면 열 수 없습니다. 링크를 숨기려면 `config.gs`의 `SHOW_DOC_LINK`를 `false`로 바꿉니다.

**같은 사람이 두 번 제출했어요.**
제출할 때마다 새 문서가 만들어집니다. 저장 폴더에서 필요 없는 문서를 지우세요. (제출 중에는 버튼이 비활성화되어 실수로 두 번 누르는 것은 막습니다)
