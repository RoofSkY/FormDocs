# 관리자 가이드

프로그래밍을 몰라도 됩니다. **Google 문서를 꾸미고, 시트에 한 줄을 추가**하면 새 신청서가 생깁니다.

## 새 신청서 만들기

### 1. 양식 문서 복사

1. 내 드라이브의 `신청서 웹앱/양식 문서` 폴더를 엽니다.
2. 예시 문서 `[양식] 예시문서`를 엽니다.
3. **파일 → 사본 만들기**를 누릅니다.

예시 문서는 자리표시자 쓰는 법을 모두 담은 연습용 문서입니다. 자세한 쓰는 법은 [자리표시자 문법](placeholder-syntax.md)을 보세요.

예시 문서를 지웠거나 망가뜨렸다면 개발 담당자에게 `resetSampleForms` 실행을 부탁하면 처음 상태로 다시 만들어집니다. ([설치 가이드](install.md#예시-문서-다시-만들기))

빈 문서에서 시작해도 됩니다. Word나 한글 파일은 Google 문서로 연 뒤 **파일 → Google 문서로 저장**한 문서를 쓰세요.

### 2. 문서 꾸미기

- 제목, 안내문, 표, 글꼴, 색은 종이 양식처럼 자유롭게 고칩니다.
- 값을 받을 자리에 `{{항목명}}`을 적습니다. 자세한 쓰는 법은 [자리표시자 문법](placeholder-syntax.md)을 보세요.
- **항목명은 한글**을 권장하고, 콜론 뒤 설정(`list`, `button`, `max`, `help`, `if` 등)과 공통 자리표시자(`{{date}}` 등)는 **영어 소문자**로 적습니다. 한글 설정(`목록선택`, `안내`)이나 대문자(`List`)는 오류입니다.
- 필수는 항목명 바로 뒤에 `*`를 붙이고, 쉼표·괄호가 들어간 글자는 큰따옴표로 감쌉니다.

```text
성명: {{아동 성명*}}          생년월일: {{생년월일: help("예) 2018-05-21")}}
성별: {{성별: list(남, 여)}}
관심 분야: {{관심 분야: button(미술, 체육, 코딩), max(2)}}
보호자 (서명) {{보호자 서명*: sign}}
```

### 3. `양식목록` 탭에 등록

템플릿 시트(`신청서 웹앱/신청서 템플릿 시트`)의 **`양식목록`** 탭에 한 줄을 추가합니다.

| 양식ID   | 양식이름    | 설명           | 양식문서    | 저장폴더ID | 파일이름                          | 하위폴더     | 사용 |
| -------- | ----------- | -------------- | ----------- | ---------- | --------------------------------- | ------------ | ---- |
| vacation | 휴가 신청서 | 연차·반차 신청 | (문서 주소) |            | `{{form_name}}_{{이름}}_{{date}}` | `{{year}}년` | ☑    |

최소한 **양식ID, 양식이름, 양식문서, 사용** 네 칸만 채우면 됩니다.

### 4. 점검

웹앱 주소 끝에 `?check=1`을 붙여 엽니다. 새 양식이 **정상**으로 나오는지 확인합니다.
오류가 있으면 어디를 어떻게 고칠지 알려 줍니다. ([문제 해결](troubleshooting.md))

점검 화면의 **신청서 열어 보기**로 실제 화면을 확인하고, 시험 삼아 한 번 제출해 결과 문서도 확인하세요.

### 5. 사용자에게 주소 알리기

```text
https://script.google.com/macros/s/…/exec?form=vacation
```

웹앱 주소를 그대로 알려 주면 사용자가 신청서 목록에서 고를 수 있습니다.

## `양식목록` 탭의 열

1행 머리글 이름으로 열을 찾습니다. **열 순서는 바꿔도 되지만 머리글 이름은 그대로 두세요.** 모르는 머리글의 열(메모용 등)은 무시합니다.

| 열           | 꼭 적기 | 설명                                                                                                                            | 예시                                        |
| ------------ | ------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `양식ID`     | ●       | 영문·숫자·`-`·`_`만 씁니다(최대 64자). 신청서 주소에 쓰이며, 다른 줄과 겹치면 안 됩니다. 대소문자만 다른 것도 같은 ID로 봅니다. | `vacation`                                  |
| `양식이름`   | ●       | 목록에 보이는 이름이며 `{{form_name}}`의 값입니다.                                                                              | `휴가 신청서`                               |
| `설명`       |         | 목록과 신청서 맨 위에 보이는 안내입니다.                                                                                        | `연차·반차 신청`                            |
| `양식문서`   | ●       | 양식 문서의 주소를 통째로 붙여 넣습니다.                                                                                        | `https://docs.google.com/document/d/…/edit` |
| `저장폴더ID` |         | 제출 문서를 저장할 Drive 폴더 주소입니다. 비우면 기본 저장 폴더에 저장합니다.                                                   | `https://drive.google.com/drive/folders/…`  |
| `파일이름`   |         | 만들어질 문서의 이름 규칙입니다. 비우면 `{{form_name}}_{{submitted_at}}`                                                        | `{{form_name}}_{{아동 성명}}_{{date}}`      |
| `하위폴더`   |         | 저장 폴더 안에 자동으로 만들 폴더입니다. `/`로 여러 단계를 만들 수 있습니다. 비우면 `{{form_name}}/{{year}}`                    | `{{year}}년 {{semester}}학기`               |
| `사용`       | ●       | 체크하면 목록에 보이고 접수합니다. 해제하면 목록에서 사라지고 주소로도 열리지 않습니다.                                         | ☑                                           |

- 행이 비어 있으면(체크 안 된 체크박스만 있는 행 포함) 건너뜁니다.
- 앞뒤 공백, 전각·반각 쉼표 차이는 알아서 처리합니다.
- `사용` 칸은 체크박스를 권장합니다. 글자로 `예`, `O`, `사용` 또는 `아니오`, `X`, `미사용` 등을 적어도 됩니다.
- 머리글이 두 번 있거나 꼭 필요한 머리글이 빠지면 오류로 알려 줍니다. (`하위폴더` 열은 없어도 됩니다)

## 저장 위치와 파일 이름

### 저장 폴더를 정하는 순서

1. `양식목록`의 `저장폴더ID`
2. `config.gs`의 기본 저장 폴더 (`setup`이 만든 `신청서 웹앱/제출 문서`)
3. 둘 다 없으면 배포 계정의 내 드라이브 맨 위 `제출 문서` 폴더 (없으면 자동으로 만듦)

위 폴더 안에 `하위폴더` 규칙대로 폴더를 자동으로 만들어 저장합니다. 같은 이름의 폴더가 있으면 그 폴더를 씁니다.
`하위폴더`를 비우면 `{{form_name}}/{{year}}`(양식이름/연도) 규칙을 씁니다.

```text
제출 문서/
└─ 휴가 신청서/
    └─ 2026/
        └─ 휴가 신청서_2026-10-13 09-30
```

`하위폴더`를 직접 적은 예:

```text
제출 문서/
└─ 2026년 2학기/
    ├─ 3학년/
    │   └─ 예시문서_홍길동_2026-10-12
    └─ 5학년/
        └─ 예시문서_김철수_2026-10-12
```

### 파일이름·하위폴더에 쓸 수 있는 이름

- 양식 문서에 있는 **항목 이름** (예: `{{아동 성명}}`)
- **공통 자리표시자**: `{{form_name}}`, `{{submitted_at}}`, `{{date}}`, `{{year}}`, `{{month}}`, `{{day}}`, `{{semester}}`, `{{submitter}}` (영어 소문자로만)

규칙:

- 여기에는 이름만 적습니다. `{{이름*}}`이나 `{{연락처: help(…)}}` 같은 설정은 적지 않습니다.
- 값이 비어 있으면 `미입력`으로 바뀝니다.
- 파일 이름에 쓸 수 없는 `\ / : * ? " < > |`는 `-`로 바뀝니다.
- 이름이 120자를 넘으면 자릅니다.
- `sign` 항목은 `서명함`으로, `agree` 항목은 고른 값(`동의`·`비동의`)으로, 여러 개 고른 항목은 쉼표로 이어서 들어갑니다.

### 권한

양식 문서와 저장 폴더는 **웹앱을 배포한 계정이 열 수 있어야** 합니다.
다른 계정이 만든 문서나 폴더를 쓰려면 배포 계정에 공유하세요. 폴더는 **편집자** 권한이 필요합니다.

## 고친 내용이 반영되는 때

| 고친 것              | 반영 시점                                                                |
| -------------------- | ------------------------------------------------------------------------ |
| 양식 문서            | 신청서를 다시 열면 바로 반영됩니다. (문서 수정 시각을 비교)              |
| `양식목록` 탭        | 최대 5분 뒤 반영됩니다. **`?check=1` 점검 화면을 열면 바로 반영됩니다.** |
| 코드(`.gs`, `.html`) | 개발 담당자가 배포 버전을 갱신해야 합니다.                               |

5분은 `config.gs`의 `CACHE_SECONDS`로 바꿀 수 있습니다.

## 웹 화면에 보이는 모습

| 문서에서                                                    | 웹 화면에서                                                                                                             |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 문단, 표(병합 칸·배경색 포함), 글머리·번호 목록             | 그대로 보입니다.                                                                                                        |
| 굵게, 기울임, 밑줄, 취소선, 글자색, 형광펜, 글자 크기, 링크 | 그대로 보입니다.                                                                                                        |
| 정렬(가운데·오른쪽·양쪽)                                    | 그대로 보입니다.                                                                                                        |
| `제목` 스타일 문단                                          | 화면 제목이 됩니다. 없으면 `양식이름`이 제목입니다.                                                                     |
| `제목 1`·`제목 2` 스타일 문단                               | 그 문단부터 화면 칸(카드)이 나뉩니다.                                                                                   |
| `{{항목명}}`                                                | 문서 속에는 값이 바로 채워지는 빈칸으로 보입니다. 입력 칸은 그 항목이 **처음 나온 문단(또는 표) 바로 아래**에 생깁니다. |
| `{{date}}` 같은 공통 자리표시자                             | 오늘 날짜 등 실제 값으로 보입니다.                                                                                      |
| 그림, 그리기                                                | 웹에는 보이지 않습니다. 결과 문서에는 그대로 들어갑니다.                                                                |
| 머리글, 바닥글                                              | 웹에는 보이지 않습니다. 결과 문서에는 그대로 들어가며 자리표시자도 채워집니다.                                          |
| 두 번째 이후 문서 탭                                        | 웹에는 첫 탭만 보입니다. 다른 탭의 자리표시자도 결과 문서에서 채워집니다.                                               |

> 꼭 읽어야 할 안내는 그림이 아니라 **글자**로 적으세요. 점검 화면에서 그림 개수를 알려 줍니다.

## 결과 문서

- 양식 문서 전체(모든 탭, 머리글·바닥글 포함)를 복사해 자리표시자를 값으로 채웁니다.
- 입력값에는 자리표시자 글자에 준 서식(글꼴·크기·굵게·색 등)이 그대로 적용됩니다. 정확히는 `{{` 바로 뒤 첫 글자의 서식을 따릅니다.
- `text` 유형에 입력한 줄바꿈은 그대로 유지됩니다.
- 서명은 그 자리에 그림(최대 160×60픽셀, 비율 유지)으로 들어갑니다. 표 칸 안에 두면 줄이 밀리지 않습니다.
- 표시조건 때문에 숨겨진 항목은 빈칸으로 들어갑니다.
- 문서에 남은 알 수 없는 `{{…}}`는 지웁니다.

### 인쇄용 빈 양식

필수(`*`) 항목이 없는 양식은 아무것도 입력하지 않고 제출하면 빈 양식 문서가 만들어집니다.
필수 항목이 있는 양식은 양식 문서를 직접 복사해 `{{…}}`를 지우는 것이 빠릅니다.

## 신청서 운영

| 하고 싶은 일            | 방법                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 접수를 잠시 멈추기      | `양식목록`의 `사용` 체크를 해제합니다. 주소로 들어오면 "지금은 접수하지 않는 신청서입니다"가 보입니다.                                                 |
| 다시 접수하기           | `사용`에 다시 체크합니다.                                                                                                                              |
| 학기마다 같은 양식 쓰기 | 문서는 그대로 두고 `하위폴더`를 `{{year}}년 {{semester}}학기`처럼 정해 두면 학기별 폴더로 나뉩니다.                                                    |
| 양식을 크게 고치기      | 운영 중인 문서를 바로 고치면 작성 중인 사람에게 "신청서가 바뀌었습니다" 안내가 나올 수 있습니다. 사본에서 고친 뒤 `양식문서` 주소를 바꾸면 안전합니다. |
| 여러 신청서를 함께 운영 | `양식목록`에 줄을 계속 추가합니다. 한 줄 = 신청서 하나입니다.                                                                                          |

## 템플릿 시트의 `사용법` 탭

이 문서의 요약본이 템플릿 시트의 `사용법` 탭에 있습니다.
`setup`을 실행할 때마다 새로 작성되므로, 메모는 다른 탭에 적으세요.
