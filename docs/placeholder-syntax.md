# 자리표시자 문법

양식 문서에서 값을 받을 자리에 적는 `{{…}}` 글자를 **자리표시자**라고 합니다.
자리표시자 하나가 웹 화면의 입력 칸 하나가 됩니다.

이 문서는 규칙만 정리합니다. 실제로 적는 예와 자주 하는 실수는 [자리표시자 예시](placeholder-examples.md)를 보세요.

## 기본 형식

```text
{{항목명}}                     글 입력 칸
{{항목명*}}                    필수
{{항목명: 설정, 설정, …}}      설정 붙이기
{{항목명*: 설정, 설정, …}}     필수 + 설정
```

| 부분 | 뜻 |
| --- | --- |
| `{{` `}}` | 양쪽에 중괄호를 **두 개씩** 적습니다. |
| `항목명` | 웹 화면에 보이는 이름이자, 결과 문서에서 값이 들어갈 자리의 이름입니다. |
| `*` | 항목명 바로 뒤에 붙이면 **필수**입니다. |
| `:` | 콜론 뒤에 설정을 쉼표로 이어 적습니다. 순서는 자유입니다. |

- `{{ }}` 안에서는 줄을 바꾸지 않습니다.
- 전각 문자(`：` `，` `＊` `（ ）` `＝`)도 같은 뜻으로 읽습니다.

## 지시자 한눈에 보기

설정에 쓰는 말을 **지시자**라고 합니다. 지시자는 **영어 소문자로만** 적습니다. 한글(`목록선택`, `필수` 등)이나 대문자(`List`)는 오류입니다.

| 지시자 | 뜻 | 쓸 수 있는 곳 |
| --- | --- | --- |
| `text` | 글 입력. 유형을 적지 않으면 `text` | 유형 |
| `list(선택지, …)` | 목록에서 고르기 | 유형 |
| `button(선택지, …)` | 버튼으로 고르기 | 유형 |
| `agree` | 동의 / 비동의 고르기 | 유형 |
| `sign` | 손가락·마우스로 서명 | 유형 |
| `max(숫자)` | 여러 개 고르기, 최대 개수 | `list`·`button`만 |
| `min(숫자)` | 여러 개 고르기, 최소 개수 | `list`·`button`만 |
| `help(문구)` | 칸 아래 안내 문구 | 모든 유형 |
| `if(조건)` | 표시조건: 조건이 맞을 때만 칸이 보임 | 모든 유형 |
| `and` / `or` | `if` 안에서 조건 여러 개를 잇기 | `if` 안 |

필수는 지시자가 아니라 항목명 뒤의 `*`입니다.

## 이름 규칙

- **항목명은 한글을 권장**합니다. 띄어쓰기도 그대로 쓸 수 있습니다.
- 영어 항목명도 되지만 대소문자를 구분합니다. (`Name`과 `name`은 다른 항목)
- 항목명에는 `*`와 `=`를 쓸 수 없습니다.
- 지시자와 같은 이름(`text`, `list`, `if` 등)은 대소문자와 상관없이 항목명으로 쓸 수 없습니다.
- [공통 자리표시자](#공통-자리표시자)와 같은 이름(`date` 등)은 입력 칸이 되지 않고 자동 값이 들어갑니다.

## 큰따옴표로 감싸기

괄호 안의 글자(선택지, 안내 문구, 조건 값)에 아래 글자가 있으면 **큰따옴표 `" "`로 감쌉니다.**

> 쉼표 `,` · 괄호 `( )` · 빗금 `/` · 등호 `=` · 큰따옴표 `"`

- 필요 없는 글자를 감싸도 됩니다.
- 둥근 따옴표(`“ ”`)도 같은 것으로 읽습니다. (Google 문서가 자동으로 바꿔도 괜찮음)
- 글자 안의 큰따옴표는 두 번(`""`) 적습니다.
- 따옴표 앞뒤의 띄어쓰기는 지웁니다.

## 유형 5종

| 유형 | 웹 화면 | 결과 문서에 들어가는 값 |
| --- | --- | --- |
| `text` | 글 입력 칸. 길게 쓰면 칸이 늘어남 | 입력한 글자 (줄바꿈 유지) |
| `list` | 하나 고르기: 펼침 목록 / 여러 개: 체크 목록 | 고른 선택지 (여러 개면 쉼표로 이어서) |
| `button` | 선택지마다 버튼 | 고른 선택지 (여러 개면 쉼표로 이어서) |
| `agree` | 동의 / 비동의 | `☑ 동의   □ 비동의` |
| `sign` | 서명판 | 서명 그림 (최대 160×60픽셀) |

- **text**: 날짜·전화번호 등 적어서 받는 값은 모두 `text`입니다. 형식은 검사하지 않으므로 `help`로 예를 보여 줍니다. 최대 글자 수는 `config.gs`의 `MAX_TEXT_LENGTH`(기본 5000자)입니다.
- **list**, **button**: 괄호 안에 선택지를 쉼표로 나눠 적습니다. 같은 선택지를 두 번 적으면 오류입니다. 필수가 아니면 선택을 취소할 수 있습니다.
- **agree**: 선택지는 `동의`, `비동의`로 정해져 있습니다. 필수여도 `비동의`로 제출할 수 있습니다. 문구를 바꾸려면 `button`을 씁니다.
- **sign**: 표 칸 안에 두면 줄이 밀리지 않습니다.
- `text`, `agree`, `sign`은 괄호를 생략할 수 있고, 괄호 안에 글자를 적으면 오류입니다.
- 입력값은 실행 로그에 남지 않습니다. 개인정보를 받을 때는 결과 문서와 저장 폴더의 공유 범위에 주의하세요.

## 여러 개 고르기 (`max`, `min`)

- `list`·`button`에만 씁니다.
- 숫자가 **2 이상**이면 여러 개 고르기가 됩니다. `max(1)`은 적지 않은 것과 같습니다.
- `max`만 적으면 최소 개수가 없고, `min`만 적으면 최대 개수는 선택지 수입니다.
- 숫자는 1 이상의 정수이고, `min` ≤ `max` ≤ 선택지 수여야 합니다.
- `max`개를 다 고르면 나머지 선택지는 누를 수 없습니다.

필수(`*`)인지에 따라 허용되는 개수가 다릅니다.

| | 아무것도 안 고름 | `min`보다 적게 고름 | `min`~`max`개 고름 |
| --- | --- | --- | --- |
| 필수 아님 | 됨 | 오류 | 됨 |
| 필수(`*`) | 오류 | 오류 | 됨 |

## 표시조건 (`if`)

앞에서 고른 값에 따라 칸을 보이거나 숨깁니다.

| 쓰는 법 | 뜻 |
| --- | --- |
| `if(항목=값)` | 항목의 값이 `값`이면 보임 |
| `if(항목=값1/값2)` | 값 중 하나라도 맞으면 보임 |
| `if(조건 and 조건)` | 모두 맞으면 보임 |
| `if(조건 or 조건)` | 하나라도 맞으면 보임 |
| `if((조건 or 조건) and 조건)` | `and`와 `or`를 섞을 때는 **괄호로 묶어야** 함 |

- 항목 하나에 `if(…)`는 하나만 적습니다.
- 조건에 쓰는 항목은:
  - 문서에서 **이 항목보다 앞에** 나와야 합니다.
  - `list`, `button`, `agree` 유형이어야 합니다.
  - 값은 그 항목의 선택지와 **똑같아야** 합니다. (`agree`는 `동의`·`비동의`)
- 여러 개 고르는 항목은 고른 것에 그 값이 **들어 있으면** 맞는 것으로 봅니다.
- 괄호는 짝이 맞아야 합니다.

조건이 맞지 않아 **숨겨진 칸**은:

- 필수여도 입력하지 않아도 됩니다.
- 입력했던 값은 버리고, 결과 문서에 빈칸으로 들어갑니다.
- 다른 항목의 조건에 쓰였다면, 값이 없는 것으로 봅니다.

## 안내 문구 (`help`)

입력 칸 아래에 작은 글씨로 안내를 보여 줍니다. 쉼표나 괄호가 있으면 큰따옴표로 감쌉니다.

## 같은 항목을 여러 곳에 쓰기

- 같은 이름을 여러 곳에 적으면 입력 칸은 하나이고, 모든 자리에 같은 값이 들어갑니다.
- 설정(`*`, 유형, `max`, `min`, `help`, `if`)은 **한 곳에만** 적고, 나머지는 이름만 적습니다. 여러 곳에 적으려면 모두 똑같아야 합니다.
- 입력 칸은 그 항목이 **처음 나온 자리** 아래에 생깁니다.

## 공통 자리표시자

입력 칸 없이 제출할 때 자동으로 채워집니다. **영어 소문자로만** 적고, 설정(`*`, `:`)을 붙일 수 없습니다.

| 자리표시자 | 값 | 값의 모양 |
| --- | --- | --- |
| `{{form_name}}` | `양식목록`의 양식이름 | 휴가 신청서 |
| `{{submitted_at}}` | 제출한 날짜와 시각 (`DATETIME_FORMAT`) | 2026-10-12 14:05 |
| `{{date}}` | 제출한 날짜 (`DATE_FORMAT`) | 2026-10-12 |
| `{{year}}` | 제출한 연도 | 2026 |
| `{{month}}` | 제출한 달 (앞에 0 없음) | 10 |
| `{{day}}` | 제출한 날 (앞에 0 없음) | 12 |
| `{{semester}}` | 3~8월이면 `1`, 그 밖에는 `2` | 2 |
| `{{submitter}}` | 제출한 사람의 이메일 (알 수 있을 때만. 지금 배포 설정에서는 항상 빈칸) | name@example.com |

- 한글 이름(`{{날짜}}` 등)은 공통 자리표시자가 아닙니다. 오류 없이 **입력 칸**이 됩니다.
- 웹 화면에서는 오늘 날짜 기준 값이 미리 보입니다.

## 쓸 수 있는 곳

| 위치 | 쓸 수 있는 것 |
| --- | --- |
| 첫 번째 문서 탭의 본문 (문단·목록·표 칸) | 모든 자리표시자. 입력 칸 설정은 **여기에만** |
| 머리글·바닥글, 두 번째 이후 문서 탭 | 공통 자리표시자, 본문에 있는 항목의 **이름만** |
| `양식목록`의 `파일이름`·`하위폴더` | 공통 자리표시자, 본문에 있는 항목의 **이름만** |
