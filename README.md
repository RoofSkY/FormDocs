# 신청서 웹앱 매뉴얼

Google Apps Script로 만든 **범용 신청서 웹앱**입니다.
관리자는 Google 문서 한 장으로 신청서를 만들고, 사용자는 웹 화면에서 작성해 제출합니다.
제출한 내용은 같은 모양의 Google 문서로 Drive에 저장됩니다.

## 핵심 개념: 문서가 곧 양식

| 양식 문서에 적은 글자 | 웹 화면 | 결과 문서 |
| --- | --- | --- |
| `성명: {{아동 성명*}}` | 성명 입력 칸 (필수) | 성명: 홍길동 |
| `성별: {{성별: select(남, 여)}}` | 남 / 여 펼침 목록 | 성별: 남 |
| `(서명) {{보호자 서명*: sign}}` | 손가락·마우스 서명 칸 | (서명) + 서명 그림 |

- **양식 문서**: 종이 양식처럼 자유롭게 꾸미고, 값을 받을 자리에 `{{항목명}}`을 적습니다.
- **웹 화면**: 양식 문서의 내용이 그대로 보이고, `{{항목명}}` 자리마다 입력 칸이 생깁니다.
- **결과 문서**: 제출하면 양식 문서를 복사한 뒤 `{{항목명}}` 자리에 입력값을 채워 저장합니다.
- **템플릿 시트의 `양식목록` 탭**: 운영할 양식 문서를 등록합니다. 한 줄이 신청서 하나입니다.
- **자리표시자 규칙**: 항목명은 한글로, 설정(`select`, `required`, `if`, `help` 등)과 공통 자리표시자(`{{date}}` 등)는 영어 소문자로 적습니다. 예) `{{보호자 연락처*: help 예) 010-1234-5678}}`

새 신청서를 만들거나 고칠 때 **코드를 고칠 일은 없습니다.**

## 빠른 시작

1. **개발 담당자**: [설치 가이드](doc/install.md)대로 `setup`을 실행하고, `config.gs`에 ID를 넣은 뒤 배포합니다.
2. **관리자**: `신청서 웹앱/양식 문서` 폴더에서 예시 문서의 사본을 만들어 고칩니다. 그다음 `양식목록` 탭에 한 줄을 추가합니다. ([관리자 가이드](doc/admin-guide.md))
3. **관리자**: 웹앱 주소 끝에 `?check=1`을 붙여 열고, 양식이 **정상**인지 확인합니다.
4. 사용자에게 `웹앱주소?form=양식ID` 주소를 알려 줍니다.

## 웹앱 주소

| 주소 | 화면 |
| --- | --- |
| `…/exec` | 신청서 목록 (`사용`에 체크된 양식만) |
| `…/exec?form=양식ID` | 해당 신청서 작성 화면 |
| `…/exec?check=1` | 관리자용 양식 점검 화면 (캐시도 비움) |
