# 사용자 안내 (신청서 작성하기)

신청서를 작성하는 보호자·참가자에게 그대로 전달할 수 있는 안내입니다.

## 작성 순서

1. 안내받은 신청서 주소를 엽니다. 휴대폰과 컴퓨터 모두 됩니다.
   - 신청서 목록이 나오면 작성할 신청서를 누릅니다.
2. 화면에 보이는 신청서 내용을 읽으며 각 입력 칸을 채웁니다.
   - 입력한 값은 위쪽 문서 속 빈칸에 바로 보입니다.
   - 문서 속 빈칸을 누르면 그 입력 칸으로 이동합니다.
   - 빨간 `*` 표시가 있는 칸은 꼭 입력해야 합니다.
3. 맨 아래 **제출하기**를 누릅니다.
   - "제출하고 있습니다" 안내가 나오는 동안 창을 닫지 마세요.
4. **제출되었습니다** 화면이 나오면 끝입니다.

## 입력 칸 사용법

| 칸 | 사용법 |
| --- | --- |
| 글 입력 칸 | 내용을 적습니다. 길게 쓰면 칸이 늘어납니다. 날짜·전화번호 등은 칸 아래 안내의 예처럼 적어 주세요. |
| 펼침 목록 | 칸을 누르고 해당하는 값을 고릅니다. |
| 버튼 | 해당하는 버튼을 누릅니다. 필수가 아니면 다시 누를 때 선택이 취소됩니다. |
| 여러 개 고르기 (버튼·체크 목록) | 해당하는 것을 모두 누릅니다. 다시 누르면 선택이 취소됩니다. 고를 수 있는 개수를 다 채우면 나머지는 흐리게 바뀌어 누를 수 없습니다. |
| 동의 (버튼) | 동의 / 비동의 중 하나를 누릅니다. |
| 서명 | 네모 칸 안에 손가락이나 마우스로 서명합니다. 다시 하려면 **지우기**를 누릅니다. |

일부 칸은 앞에서 고른 값에 따라 나타나거나 사라집니다. 예) 귀가방식에서 "동행귀가"를 고르면 "동행인" 칸이 나타납니다.

## 제출이 안 될 때

| 메시지 | 할 일 |
| --- | --- |
| 입력하지 않았거나 잘못된 항목이 N개 있습니다 | 빨간 글씨가 나온 칸을 고친 뒤 다시 제출합니다. |
| 인터넷 연결을 확인한 뒤 다시 시도해 주세요 | 연결을 확인하고 다시 제출합니다. 입력한 내용은 그대로 남아 있습니다. |
| 신청서가 바뀌었습니다 | 페이지를 새로고침한 뒤 다시 작성합니다. |
| 지금은 접수하지 않는 신청서입니다 | 접수 기간이 아닙니다. 담당자에게 문의합니다. |
| 관리자 확인 사항이 보이는 화면 | 신청서 설정 문제입니다. 화면 내용을 담당자에게 알려 줍니다. |

## 제출한 뒤

- 제출 완료 화면의 **새로 작성하기**로 같은 신청서를 한 번 더 작성할 수 있습니다. 예) 자녀가 여러 명일 때
- 제출한 내용은 담당 기관의 Google Drive에 문서로 저장됩니다.
- 잘못 제출했다면 다시 제출한 뒤 담당자에게 알려 주세요. 제출한 문서는 사용자가 직접 고치거나 지울 수 없습니다.
