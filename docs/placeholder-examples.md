# 자리표시자 예시

[자리표시자 문법](placeholder-syntax.md)의 규칙을 실제로 적는 예입니다.
모든 문법을 쓴 양식은 템플릿 시트에 함께 만들어지는 `[양식] 예시문서`에서도 볼 수 있습니다.

## 기본

| 쓰는 법 | 뜻 |
| --- | --- |
| `{{이름}}` | 글 입력 |
| `{{아동 성명*}}` | 필수 글 입력 |
| `{{생년월일: help("예) 2018-05-21")}}` | 글 입력 + 칸 아래 안내 문구 |
| `{{성별*: list(남, 여)}}` | 펼침 목록에서 하나 고르기 (필수) |
| `{{학년: button(1학년, 2학년, 3학년)}}` | 버튼 중 하나 고르기 |
| `{{개인정보 동의*: agree}}` | 동의 / 비동의 고르기 (필수) |
| `{{보호자 서명*: sign}}` | 서명 (필수) |
| `{{과목: max(2), list(국어, 수학, 과학)}}` | 설정 순서는 자유 |

## 큰따옴표로 감싸기

```text
{{연락처: help("예) 010-1234-5678")}}            괄호가 있음
{{1순위 관계: help("예) 부, 모, 조부")}}          괄호·쉼표가 있음
{{장비: button("개인 노트북(대여)", 기관 노트북)}}
{{교통: list("버스/지하철", 자가용)}}             빗금이 있음
{{성별: list("남", "여")}}                       필요 없어도 감싸도 됨
{{확인: help("""예""를 고르세요")}}               화면에는 "예"를 고르세요
```

## 여러 개 고르기

```text
{{과목: list(국어, 수학, 과학, 영어), max(2)}}            최대 2개
{{관심 분야: button(미술, 체육, 코딩, 독서), min(2)}}      고르면 2개 이상
{{활동*: button(미술, 체육, 코딩, 독서), min(2), max(3)}}  2~3개 (필수)
```

| 쓰는 법 | 아무것도 안 고름 | 1개 | 2개 이상 |
| --- | --- | --- | --- |
| `{{과목: list(…), min(2)}}` | 됨 | 오류 | 됨 |
| `{{과목*: list(…), min(2)}}` | 오류 | 오류 | 됨 |
| `{{과목*: list(…), max(3)}}` | 오류 | 됨 | 3개까지 됨 |

## 표시조건

```text
· 귀가방식: {{귀가방식*: list(자율귀가, 동행귀가)}}
  동행인: {{동행인*: if(귀가방식=동행귀가)}}
· 귀가방법: {{귀가방법: button(도보, 대중교통, 기타)}} {{기타 귀가방법: if(귀가방법=기타)}}
```

| 쓰는 법 | 뜻 |
| --- | --- |
| `if(귀가방법=도보/기타)` | 도보나 기타를 고르면 보임 |
| `if(교통="버스/지하철")` | 값에 `/`가 있어 큰따옴표로 감쌈 |
| `if(관심 분야=코딩)` | 여러 개 고르는 항목에서 코딩을 포함해 고르면 보임 |
| `if(개인정보 동의=동의)` | `agree` 항목에서 동의를 고르면 보임 |
| `if(사진 동의=동의 or 영상 동의=동의)` | 둘 중 하나라도 동의하면 보임 |
| `if(사진 동의=동의 and 영상 동의=동의)` | 둘 다 동의하면 보임 |
| `if((사진 동의=동의 or 영상 동의=동의) and 만 14세 미만=예)` | `and`·`or`를 섞을 때는 괄호로 묶음 |
| `if((A=동의) or (B=동의))` | 섞지 않을 때도 조건마다 괄호를 써도 됨 |
| `{{법정대리인 서명*: sign, if(만 14세 미만=예)}}` | 조건부 필수 서명 |

## 안내 문구

```text
{{귀가요청시간: help(24시간제로 적어 주세요)}}
{{귀가요청시간: help("24시간제로 적어 주세요. 예) 18:30")}}
{{연락처: help("예) 010-1234-5678")}}
```

## 같은 항목을 여러 곳에 쓰기

```text
보호자 연락처 표:   1순위 성명 {{1순위 성명*}}
문서 맨 아래:       보호자: {{1순위 성명}}   (서명) {{보호자 서명*: sign}}
```

## 공통 자리표시자

```text
{{form_name}}_{{이름}}_{{date}}       양식목록의 파일이름
{{year}}년 {{semester}}학기            양식목록의 하위폴더
{{신청 날짜}}                          date와 겹치지 않게 다른 이름으로 입력받기
```

## 문구를 바꾼 동의

`agree`의 문구는 바꿀 수 없으므로 `button`을 씁니다.

```text
{{사진 활용: button(동의합니다, 동의하지 않습니다)}}
```

## 자주 하는 실수

| 잘못 적은 예 | 고친 예 | 이유 |
| --- | --- | --- |
| `{이름}`, `{{이름}` | `{{이름}}` | 중괄호는 양쪽에 두 개씩 |
| `{{성별 list(남, 여)}}` | `{{성별: list(남, 여)}}` | 설정 앞에 콜론(`:`) |
| `{{성별: list(남, 여}}` | `{{성별: list(남, 여)}}` | 괄호 짝 |
| `{{성별: 라디오(남, 여)}}` | `{{성별: button(남, 여)}}` | 유형은 5종 이름 그대로 |
| `{{성별: 목록선택(남, 여)}}` | `{{성별: list(남, 여)}}` | 한글 지시자는 받지 않음 |
| `{{성별: List(남, 여)}}` | `{{성별: list(남, 여)}}` | 지시자는 영어 소문자로만 |
| `{{이름: *text}}` | `{{이름*}}` | 필수는 항목명 바로 뒤의 `*` |
| `{{연락처: help(예) 010-…)}}` | `{{연락처: help("예) 010-…")}}` | 문구 속 괄호에서 끝난 것으로 읽힘 |
| `{{관계: help(예: 부, 모)}}` | `{{관계: help("예: 부, 모")}}` | 문구 속 쉼표에서 나뉘어 읽힘 |
| `{{동행인: 귀가방식=동행귀가}}` | `{{동행인: if(귀가방식=동행귀가)}}` | 표시조건 앞에 `if` |
| `if(A=동의 or B=동의 and C=예)` | `if((A=동의 or B=동의) and C=예)` | `and`·`or`를 섞을 때는 괄호로 묶기 |
| `if(귀가방법=도보 or 기타)` | `if(귀가방법=도보/기타)` | 한 항목의 값 여러 개는 `/`로. `or`는 조건 사이에만 |
| `{{사진: agree(예, 아니오)}}` | `{{사진: button(예, 아니오)}}` | `agree`의 문구는 바꿀 수 없음 |
| `{{과목: list(국어, 수학), max(3)}}` | `{{과목: list(국어, 수학), max(2)}}` | `max`는 선택지 수 이하 |
| `{{과목: list(…), min(3), max(2)}}` | `{{과목: list(…), min(2), max(3)}}` | `min`은 `max` 이하 |
| `{{이름: text, max(10)}}` | `{{이름}}` | `max`·`min`은 `list`·`button`에만 |
| `{{이름: text(가, 나)}}` | `{{이름}}` | `text`·`agree`·`sign`의 괄호 안은 비워 둠 |
| `{{Date}}` | `{{date}}` | 공통 자리표시자는 소문자로만 |
| `{{날짜}}` (오늘 날짜를 넣으려고) | `{{date}}` | 한글 이름은 공통 자리표시자가 아니라 **입력 칸**이 됨 (오류 없음) |
| 앞에 `{{이름*}}`, 뒤에 `{{이름: text}}` | 한 곳에만 `{{이름*}}`, 나머지는 `{{이름}}` | 같은 항목의 설정이 서로 다름 |
| `{{동행인: if(귀가방식=동행)}}` | `{{동행인: if(귀가방식=동행귀가)}}` | 조건 값은 선택지와 똑같이 |
| `{{date*}}` | `{{신청 날짜*}}` | 공통 자리표시자에는 설정 불가 |
