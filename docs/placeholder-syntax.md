# 자리표시자 문법

양식 문서에서 값을 받을 자리에 적는 `{{…}}` 글자를 **자리표시자**라고 합니다.
자리표시자 하나가 웹 화면의 입력 칸 하나가 됩니다.

> **가장 중요한 규칙**
> - **항목명은 한글**로 적습니다. 예) `{{보호자 연락처}}`
> - **지시자**(유형·`required`·`if`·`or`·`help`)와 **공통 자리표시자**(`{{date}}` 등)는 **영어 소문자로만** 적습니다.
> - 한글 지시자(`목록선택`, `필수`, `안내` 등)나 대문자(`Select`, `{{Date}}`)는 오류입니다.

## 지시자 한눈에 보기

| 지시자 | 뜻 | 쓰는 예 |
| --- | --- | --- |
| `text` | 글 입력 (유형을 적지 않으면 `text`) | `{{이름}}` |
| `select(…)` | 펼침 목록에서 하나 고르기 | `{{성별: select(남, 여)}}` |
| `multi(…)` | 여러 개 고르기 | `{{과목: multi(국어, 수학)}}` |
| `agree` | 동의함 / 동의하지 않음 고르기 | `{{개인정보 동의*: agree}}` |
| `sign` | 손가락·마우스로 서명 | `{{보호자 서명*: sign}}` |
| `required` | 필수 (이름 뒤 `*`와 같음) | `{{과목: required, multi(국어, 수학)}}` |
| `if 항목=값` | 표시조건: 앞 항목에서 그 값을 골랐을 때만 보임 | `{{동행인*: if 귀가방식=동행귀가}}` |
| `or` | 표시조건의 여러 값을 잇기 (`/`와 같음) | `if 귀가 방법=보호자 동행 or 기타` |
| `help …` | 칸 아래 안내 문구 (맨 뒤) | `{{연락처: help 예) 010-1234-5678}}` |

## 기본 형식

```text
{{항목명}}
{{항목명*}}
{{항목명: 설정, 설정, …}}
{{항목명*: 설정, 설정, …}}
```

| 부분 | 뜻 |
| --- | --- |
| `{{` `}}` | 양쪽에 중괄호를 **두 개씩** 적습니다. |
| `항목명` | 웹 화면에 보이는 이름이자 결과 문서에서 값이 들어갈 자리의 이름입니다. 한글·띄어쓰기를 그대로 쓸 수 있습니다. |
| `*` | 이름 바로 뒤에 붙이면 **필수**입니다. 설정에 `required`라고 적어도 같습니다. |
| `:` | 콜론 뒤에 설정을 쉼표로 이어 적습니다. |
| 설정 | **유형**, `required`, **표시조건**(`if 항목=값`), `help`(맨 뒤) |

- 전각 문자(`：`, `，`, `＊`, `（ ）`)도 같은 뜻으로 읽습니다.
- `{{ }}` 안에서는 줄을 바꾸지 마세요.
- 항목명에는 `*`와 `=`를 쓸 수 없습니다.

## 예시 모음

| 쓰는 법 | 뜻 |
| --- | --- |
| `{{이름}}` | 글 입력 (유형을 적지 않으면 `text`) |
| `{{아동 성명*}}` | 필수 글 입력 |
| `{{생년월일: help 예) 2018-05-21}}` | 글 입력 + 칸 아래 안내 문구 |
| `{{성별: select(남, 여)}}` | 펼침 목록에서 하나 고르기 |
| `{{성별*: select(남, 여)}}` | 필수로 하나 고르기 |
| `{{과목: multi(국어, 수학, 과학)}}` | 여러 개 고르기 |
| `{{동행인*: if 귀가방식=동행귀가}}` | `귀가방식`에서 `동행귀가`를 골랐을 때만 보이는 필수 칸 |
| `{{법정대리인 서명*: sign, if 만 14세 미만=예}}` | 조건부 필수 서명 |

## 유형 5종

| 유형 | 쓰는 예 | 웹 화면 | 결과 문서에 들어가는 값 |
| --- | --- | --- | --- |
| `text` (글) | `{{이름}}` | 글 입력 칸 (유형을 적지 않으면 `text`). 길게 쓰면 칸이 늘어남 | 입력한 글자 (줄바꿈 유지) |
| `select` (펼침 목록) | `{{성별: select(남, 여)}}` | 펼침 목록에서 하나 고르기 | 고른 선택지 |
| `multi` (여러 개 선택) | `{{과목: multi(국어, 수학, 과학)}}` | 여러 개 고르기 | 고른 선택지를 쉼표로 이어서 |
| `agree` (동의) | `{{개인정보 동의: agree}}` | 동의함 / 동의하지 않음 고르기 | `☑ 동의함   □ 동의하지 않음` |
| `sign` (서명) | `{{보호자 서명: sign}}` | 손가락·마우스로 서명 | 서명 그림 |

### 유형별 참고

- **text**: 이름·날짜·시간·전화번호·주민등록번호·긴 의견 등 적어서 받는 값은 모두 `text`로 받습니다. 형식은 검사하지 않으므로 `help`에 예를 적어 주세요. 예) `{{연락처: help 예) 010-1234-5678}}`
- **text**의 최대 글자 수는 `config.gs`의 `MAX_TEXT_LENGTH`에서 바꿀 수 있습니다. (기본 5000자)
- 입력값은 실행 로그에 남지 않습니다. 주민등록번호 같은 개인정보를 받을 때는 결과 문서와 저장 폴더의 공유 범위에 주의하세요.
- **select**: 필수가 아니면 목록 맨 위의 `선택하세요`를 골라 선택을 취소할 수 있습니다.
- **agree**: 괄호로 문구를 바꿀 수 있습니다. 예) `{{사진 활용: agree(동의합니다, 동의하지 않습니다)}}`
- **sign**: 결과 문서에서 최대 160×60픽셀로 줄여 넣습니다. 표 칸 안에 두면 줄이 밀리지 않습니다.

## 선택지

고르는 유형(`select`, `multi`, `agree`)은 괄호 안에 선택지를 적습니다. 선택지는 값이므로 한글로 적습니다.

```text
{{성별: select(남, 여)}}
{{성별: select(남/여)}}      ← 쉼표가 없으면 / 로 나눕니다
```

- 선택지는 쉼표(`,` `，` `、`)로 나눕니다. 쉼표가 하나도 없으면 `/`로 나눕니다.
- 같은 선택지를 두 번 적으면 오류입니다.
- `agree`는 괄호를 생략하면 `동의함`, `동의하지 않음`을 씁니다.
- 고르는 유형이 아닌데 괄호를 쓰면 오류입니다. 예) `{{이름: text(가, 나)}}`

## 표시조건

앞에서 고른 값에 따라 입력 칸을 보이거나 숨깁니다.

```text
· 귀가방식: {{귀가방식*: select(자율귀가, 동행귀가)}}
  동행인: {{동행인*: if 귀가방식=동행귀가}}
· 귀가방법: {{귀가방법: select(도보, 대중교통, 기타)}} {{기타 귀가방법: if 귀가방법=기타}}
```

- 형식은 `if 항목=값`입니다. 앞에 `if`를 꼭 붙입니다. `if` 없이 `항목=값`만 적으면 오류입니다.
- 여러 값은 `/` 또는 `or`로 잇습니다. 예) `if 귀가방법=버스/기타`, `if 귀가 방법=보호자 동행 or 기타`
- 조건에 쓰는 항목은:
  - 문서에서 **이 항목보다 앞에** 나와야 합니다.
  - `select`, `multi`, `agree` 유형이어야 합니다.
  - 값은 그 항목의 선택지에 있는 값과 **똑같아야** 합니다.
- 표시조건은 항목 하나에 하나만 적을 수 있습니다.
- 조건에 맞지 않아 숨겨진 칸은:
  - 필수(`*`)여도 입력하지 않아도 됩니다.
  - 입력했던 값은 버리고, 결과 문서에 빈칸으로 들어갑니다.
- 조건에 쓴 항목이 숨겨지면 그 항목에 걸린 칸도 함께 숨겨집니다.

## 안내 문구 (`help`)

입력 칸 아래에 작은 글씨로 안내를 보여 줍니다.

```text
{{귀가요청시간: help 24시간제로 적어 주세요. 예) 18:30}}
{{1순위 관계: help 예) 부, 모, 조부}}
```

- `help`는 설정의 **맨 뒤**에 적습니다. `help` 뒤의 글자는 쉼표가 있어도 끝까지 안내 문구가 됩니다.
- `help:`처럼 콜론을 붙여도 됩니다.

## 같은 항목을 여러 곳에 쓰기

같은 이름을 여러 곳에 적으면 입력 칸은 하나만 생기고, 모든 자리에 같은 값이 들어갑니다.

```text
보호자 연락처 표:   1순위 성명 {{1순위 성명*}}
문서 맨 아래:       보호자: {{1순위 성명}}   (서명) {{보호자 서명*: sign}}
```

- 설정(`*`, 유형, 조건, `help`)은 **한 곳에만** 적고, 나머지는 `{{1순위 성명}}`처럼 이름만 적습니다.
- 여러 곳에 설정을 적으려면 모두 똑같아야 합니다. 다르면 오류입니다.
- 입력 칸은 그 항목이 **처음 나온 자리** 아래에 생깁니다.

## 공통 자리표시자

입력 칸 없이 제출할 때 자동으로 채워집니다. 설정(`*`, `:`)을 붙일 수 없습니다. **영어 소문자로만** 적습니다.

| 자리표시자 | 값 | 예 |
| --- | --- | --- |
| `{{form_name}}` | `양식목록`의 양식이름 | 휴가 신청서 |
| `{{submitted_at}}` | 제출한 날짜와 시각 (`DATETIME_FORMAT`) | 2026-10-12 14:05 |
| `{{date}}` | 제출한 날짜 (`DATE_FORMAT`) | 2026-10-12 |
| `{{year}}` | 제출한 연도 | 2026 |
| `{{month}}` | 제출한 달 (앞에 0 없음) | 10 |
| `{{day}}` | 제출한 날 (앞에 0 없음) | 12 |
| `{{semester}}` | 3~8월이면 `1`, 그 밖에는 `2` | 2 |
| `{{submitter}}` | 제출한 사람의 이메일 (알 수 있을 때만. 지금 배포 설정에서는 항상 빈칸) | name@example.com |

- 이름이 공통 자리표시자와 같은 항목을 입력받으려면 다른 이름을 쓰세요. 예) `{{신청 날짜}}`
- 예전 한글 이름(`{{날짜}}`, `{{양식이름}}` 등)은 이제 공통 자리표시자가 아닙니다. 오류 없이 **`날짜`라는 입력 칸**이 생기므로 주의하세요.
- 웹 화면에서는 오늘 날짜 기준 값이 미리 보입니다.

## 쓸 수 있는 곳

| 위치 | 쓸 수 있는 것 |
| --- | --- |
| 첫 번째 문서 탭의 본문 (문단·목록·표 칸) | 모든 자리표시자 (입력 칸 설정은 **여기에만**) |
| 머리글·바닥글 | 공통 자리표시자, 본문에 있는 항목의 **이름만** (`{{아동 성명}}`) |
| 두 번째 이후 문서 탭 | 머리글·바닥글과 같음 |
| `양식목록`의 `파일이름`·`하위폴더` | 공통 자리표시자, 본문에 있는 항목의 **이름만** |

## 자주 하는 실수

| 잘못 적은 예 | 고친 예 | 이유 |
| --- | --- | --- |
| `{이름}`, `{{이름}` | `{{이름}}` | 중괄호는 양쪽에 두 개씩 |
| `{{성별 select(남, 여)}}` | `{{성별: select(남, 여)}}` | 설정 앞에 콜론(`:`) |
| `{{성별: select(남, 여}}` | `{{성별: select(남, 여)}}` | 괄호 짝 |
| `{{성별: 라디오(남, 여)}}` | `{{성별: select(남, 여)}}` | 유형은 5종 이름 그대로 |
| `{{성별: 목록선택(남, 여)}}` | `{{성별: select(남, 여)}}` | 한글 지시자는 받지 않음 |
| `{{성별: Select(남, 여)}}` | `{{성별: select(남, 여)}}` | 지시자는 영어 소문자로만 |
| `{{동행인: 귀가방식=동행귀가}}` | `{{동행인: if 귀가방식=동행귀가}}` | 표시조건 앞에 `if` |
| `{{Date}}` | `{{date}}` | 공통 자리표시자는 소문자로만 |
| `{{날짜}}` (오늘 날짜를 넣으려고) | `{{date}}` | 한글 이름은 공통 자리표시자가 아니라 **입력 칸**이 됨 (오류 없음) |
| 앞에 `{{이름*}}`, 뒤에 `{{이름: text}}` | 한 곳에만 `{{이름*}}`, 나머지는 `{{이름}}` | 같은 항목의 설정이 서로 다름 |
| `{{동행인: if 귀가방식=동행}}` | `{{동행인: if 귀가방식=동행귀가}}` | 조건 값은 선택지와 똑같이 |
| `{{date*}}` | `{{신청 날짜*}}` | 공통 자리표시자에는 설정 불가 |
| `{{사유: help …, required}}` | `{{사유*: help …}}` | `help` 뒤는 모두 안내 문구 |
